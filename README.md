An elegant portfolio built with Next.js 16, React 19, TypeScript, and Tailwind CSS v4.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

Key entry points:

- `src/app/page.tsx`: Landing page with hero and featured projects
- `src/components/ProjectCard.tsx`: Reusable project card
- `src/app/layout.tsx`: Shared layout, navigation, and footer

## Deployment

Recommended: deploy to Vercel.

1. Push this repo to GitHub
2. Import the repo in Vercel and deploy

Alternatives: Netlify or GitHub Pages (`next export`), noting some features may be limited without a Node runtime.
